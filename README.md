# minimal-repo

A minimal reference repository that still satisfies core repository standards.

## Purpose

This example shows the smallest reasonable repository that remains clear, documented, and publishable. It is useful as a baseline for small utilities, starter projects, or documentation-first repositories.

## Included

- Clear README
- LICENSE
- CONTRIBUTING guide
- Basic directory structure
- Small source example

## Structure

```text
src/
  hello.txt
```

## Notes

This example intentionally avoids advanced workflows, testing, or CI so that it remains genuinely minimal while still meeting baseline quality expectations.
